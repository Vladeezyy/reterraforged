# Тест-план ReTerraForged

Версия: **0.0.29** (`origin/main` 76ca052), порты 1.21.11, 26.1.2, 26.2, 26.3. Составлен 2026-11-06.

## 1. Кратко

План покрывает **235 проверок** в 20 разделах: сборка, жизненный цикл, детерминизм, рельеф, реки, острова, биомы, поверхность,
структуры, спавн, пресеты, GUI, сеть, совместимость, производительность, сбои, переводы, регрессия по issues и сами тесты.
План опирается на то, что уже есть в `tools/` и `rtf ...`, и отдельно помечает, что нужно написать.

Часть проверок я сразу прогнал на настоящих серверах 1.21.1 NeoForge, чтобы отделить настоящие дефекты от подозрений. Итог:
**40 дефектов и замечаний**, из них 24 воспроизведены запуском, остальные следуют из кода. Исправления на ветках `fix/test-plan-defects` (1.21.1) и `fix/test-plan-defects-<версия>` (порты): статус каждого дефекта в разделе 4a, цифры в приложениях C и D.

Что важнее всего:

1. **Слайдеры контрольных точек ломают мир (D-01).** Клик по Deep Ocean на 20 % даёт 0,448, на 80 % даёт 0,25. Скачок виден в вашей `rtf-widgets.txt` от 3 ноября, но тест пишет «0 failures».
2. **`tileSize=8` вешает сервер навсегда (D-02).** Испорченный `performance.conf` не даёт открыть мир (D-03), а `lowlandSwamps=99` в пресете не даёт запустить сервер (D-04). `rtf stress abuse` падает на этом сейчас: для 0.0.29 его не запускали.
3. **Спавн `ISLANDS` в океане на 10 из 20 сидов (D-14). Измерение другого мода на шуме `minecraft:overworld` становится сплошным океаном (D-29).**
4. **Все причины #38 найдены и измерены (D-06…D-09).** Острова совпадают на 100 % у разных сидов; над водой 13,9 % пляжа; Island Coast и Inland не меняют рельеф ни в одной из 25 738 клеток.
5. **Новый комментарий в #28 (ArkAstral, 6 ноября) подтвердился (D-37).** С BoP и Terralith при 12/12 в долинах рек лежат 62 % болот, широких 1 %. Highest Swamps работает на всех 8 биомах из его списка, а Lowland Swamps меняет только 4 из них. Таблица для ответа игроку: приложение A.
6. **Производительность (D-27).** На длинном прогоне 47 % тайлов считаются повторно из-за `dropAtChunk`. Без удаления повторов нет и скорость выше на 8 %, но пик кучи 2,8 ГБ против 1,7 ГБ. Куча RTF примерно в 4 раза больше ванильной: 1221 против 289 МБ после GC.

Порядок работ и критерии релиза: раздел 8. Что запускалось и какие числа получились: приложение A.

## 3. Что уже есть

Инструменты сильные: настоящие серверы, клиент с кликами, снимок мира до бита, стресс по всем настройкам. План опирается на них.

| Средство | Что делает | В CI |
|---|---|---|
| `tools/servertest.sh` | Сервер, экспорт пресета, `rtf selftest`, `rtf structures`, сравнения; опции `SEED`, `PRESET`, `LEGACY`, `NOPRESET`, `MODS`, `EXTREMES`, `FINGERPRINT_REF`, `TILECACHE`, `SWAMPS`, `SNOWGRID`, `SURFACEMAPS` | Частично: `structures` и `FINGERPRINT` выключены |
| `tools/clienttest.sh` | Клиент: мир, `gui` (создание мира кликами), `widgets` (все слайдеры) | Нет |
| `tools/uiparity.sh` | Мир из GUI = мир из датапака | Нет |
| `tools/stressworld.sh`, `rtf stress [N\|abuse\|effects\|curves]` | Крайние и случайные настройки | Нет |
| `tools/benchmark.sh`, `benchrepeat.sh` | Скорость против ванили, spark, JFR | Нет |
| `tools/compareheights.py`, `comparefingerprint.py` | Сравнение прогонов | Только `parity` |
| `rtf holes`, `floating`, `strata`, `snowline`, `snowgrid`, `swamps`, `surfacemap`, `tilecache`, `tilebench`, `weather`, `extremes`, `dungeons`, `biomemods`, `locate`, `valleys`, `previewmap` | Узкие проверки | Только `weather` |
| `common/src/test` | Один unit-тест на C2ME | Да |

Главные пробелы:

1. **Почти нет unit-тестов.** Простые логические ошибки ловятся только запуском целого сервера или не ловятся вообще.
2. **Тесты проверяют «что-то изменилось», а не «изменилось правильно».** `RTFWidgetTest` прошёл `Deep Ocean` с его скачками: 672 использования виджетов, 0 ошибок.
3. **CI запускает меньше, чем уже написано.** Нет `rtf structures`, снимка мира, клиента, стресса.
4. **Один сид и один пресет** в основном прогоне; `rtf stress` проверяет «не упало», а не форму мира.
5. **Нет проверок сбоев:** нехватка памяти, ошибка в потоке тайла, испорченный файл настроек.
6. **Windows только руками.**

## 4. Что нашёл первый проход

Строгость: **S1** зависание, краш или порча мира; **S2** функция работает неправильно и обхода нет; **S3** заметно в особых
условиях; **S4** мелочь или ограничение.

Как подтверждено: **запуск** — воспроизведено на настоящем сервере 1.21.1 NeoForge, числа в приложении; **таблица** — видно в
`rtf-widgets.txt` от настоящего прогона клиента; **код** — следует из чтения кода и подсчёта, запуском не проверялось.

Ни один дефект не исправлен: это только список. Строки указаны для `main`; пути от `common/src/main/java/raccoonman/reterraforged/`.

### 7.2. Новые серверные проверки

Черновик лежит в [`probes/RTFProbe.java`](probes/RTFProbe.java): команда `rtf probe ...`, которой сняты числа из приложения A. Это код
проверок, а не часть мода, в сборку он не входит. Чтобы включить: перенести в `server/`, зарегистрировать в `RTFSelfTest`, для `regen`
добавить счётчики в `TileGenerator.generate`, в `tools/servertest.sh` добавить опцию `PROBES=1`.

| `rtf probe seam` | Шаг на границах тайлов против шага внутри, расхождение соседних тайлов | TER-09 |
| `rtf probe biome` | Биом в чанке против биома из источника | BIO-03, ISL-07 |
| `rtf probe spawn` | Точка спавна, блок, рельеф, биом | SPW-01…03 |
| `rtf probe regen` | Сколько тайлов считалось повторно (нужны счётчики в `TileGenerator`) | PERF-05 |
